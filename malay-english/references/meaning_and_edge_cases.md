# Meaning-preserving rewriting and difficult cases

These are project review conventions, not externally imposed Malay grammar rules.
Check the complete source and candidate, not only the switched words.

| Source distinction | Preserve | Typical mistake |
|---|---|---|
| “Not yet” / “never” / “no longer” | `belum` / `tak pernah` / context-appropriate cessation | Replacing them all with `tak`. |
| “You may” / “you must” / “you should” | Permission, obligation, advice | Substituting `mesti` for `boleh`. |
| “May not arrive” / “may not enter” | Possibility versus prohibition | Assuming every *may not* means a ban. |
| “We” including/excluding the hearer | `kita` versus `kami` when resolved | Adding or removing the hearer from the group. |
| `dia` without gender | Keep gender unresolved | Choosing *he* from a masculine-sounding name. |
| “Not all files” / “all files were not…” | Quantifier scope | Turning a partial failure into total failure. |
| “Only if” / “if” | Necessary versus merely sufficient condition | Dropping *only*. |
| “Unless it rains” / “even if it rains” | Opposite condition behavior | Replacing both with `kalau`. |
| “By Friday” / “on Friday” / “before Friday” | Deadline versus event day versus strict precedence | Translating all to `pada hari Jumaat`. |
| “Increased by 20” / “increased to 20” | Change amount versus final value | Keeping the number but changing its role. |
| “Twice a day” / “every two days” | Frequency | Changing medication or appointment frequency. |
| “Lent” / “borrowed” | Who owns and who receives | Swapping participant roles. |
| “Was told to send” / “sent” | Reported instruction versus completion | Inventing a completed action. |
| “They said, ‘Don't wait.’” | Quote and speaker | Making the narrator issue that instruction. |

Do not add religious expressions, food, kinship, geography or local institutions
to make a line sound Malay. A source about a train ticket should not acquire an
MRT station name. Keep the actual currency and units. Preserve a speaker's
confidence: *maybe*, `mungkin`, *I think*, and `rasanya` are not disposable fillers.

Idioms require meaning-level interpretation. A literal word-for-word rendering of
*give up*, *on the same page* or *running late* can change the event. If a technical
term has several senses, keep it in English while translating surrounding structure
instead of choosing an unsupported Malay sense. If ambiguity matters and cannot
be preserved naturally, record it as unresolved.

For long turns, map each clause to its source clause. Then reread the whole turn
to check that reference, contrast, chronology and politeness remain coherent.
Short independent utterances may be monolingual inside a bilingual conversation;
do not force each turn to switch unless the generation brief explicitly requires
it. A strict per-clip benchmark subset is a selection choice, not a description
of all bilingual communication.

Repair a failed sentence by changing the relevant construction. Replacing a few
tokens until a language ratio passes is not semantic review. Preserve the original,
the proposed repair and the reason. Recheck the repaired text, since a grammatical
fix can introduce a new role or time error.
