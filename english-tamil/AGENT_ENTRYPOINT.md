# Agent entrypoint

Start with [SKILL.md](SKILL.md), which selects the task mode and sets the shared
meaning and annotation contract. Use [the detailed reference](references/linguistic_details.md)
when choosing a construction and [the review checklist](review_checklist.md)
before accepting it. The [input guide](references/english_input_examples.md)
explains how English, Tamil and mixed inputs are handled.

The calling workflow supplies sources, model/tool choices, output schema and
coverage targets. This rulebook does not choose them. Keep the original source
and review the exact final output; do not treat a format pass as a language review.
